# SudaTab

网格化的浏览器新标签页。时钟、搜索框、常用站点都是画布上的方块，位置和大小都能改。

## 特点

- **一切皆方块** —— 24 列网格，图标、时钟、搜索框、引语都是可拖动的块
- **拖动吸附整格** —— 拖起时轻微放大并留下原位虚坑，松手自动避让
- **右键调布局** —— 1x1 / 2x1 / 1x2 / 2x2 / 4x2 五档
- **图标可自定义** —— 抓取网站图标、文字图标（自定义文字 + 颜色）、本地上传
- **四套背景 · 网格密度 · 布局锁定**
- **Ctrl+F 本地搜索**

## 安装

1. 打开 `edge://extensions`（Chrome 同理用 `chrome://extensions`）
2. 打开「开发人员模式」
3. 点「加载解压缩的扩展」，选中本目录

想让启动浏览器时也显示它：Edge 设置 → 启动、主页和新建标签页 → 启动时 → 「打开新标签页」。

## 说明

- 数据存在 `chrome.storage.local`，不上传任何服务器
- 图标优先取站点自托管的 `apple-touch-icon.png` / `favicon.ico`，失败再退到第三方服务
- 纯静态，无构建步骤，改完代码在扩展页点刷新即可

## 文件

```
manifest.json   MV3 声明，接管新标签页
newtab.html     页面骨架
styles.css      全部样式与四套背景
app.js          网格布局、拖动、右键菜单、图标编辑器
```
