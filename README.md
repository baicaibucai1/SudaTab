# SudaTab

网格化的浏览器新标签页。时钟、搜索框、常用站点、引语都是画布上**独立的方块**，
位置直接拖动、大小在右键里切换，整页严格对齐同一套网格。不是固定居中排布的导航页。

## 特点

- **一切皆方块** —— 24 列网格（设置里 12–64 列连续可调，大屏也不挤），1×1 恒为正方形
- **iOS 式挤入重排** —— 按住即拖、严格吸附整格；其它方块就近让位（常常直接与你交换位置），松手弹性落位
- **只站格点，不站半格** —— 站点方块横向按 2 列、纵向按 3 行（一个格子的整数倍）落位，
  拖到哪儿都只会停在格点上，不会和同排的图标错开半条；旧布局里停在半格的方块，载入时自动拉回
- **右键调布局** —— 1x1 / 2x1 / 1x2 / 2x2 / 4x2 五档；空白处右键可添加、换壁纸、搜索、备份
- **图标可自定义** —— 抓取网站图标（按域名缓存，不再每次重新抓）、文字图标（自定义文字 + 13 色）、本地上传（≤512KB）
- **图标为主** —— 1x1 的方块就是图标本身：白色圆角应用图标铺满整格，名称作为独立标签
  挂在方块下方（不参与图标的裁切，长名字也不会被切掉）；2x2 / 2x1 / 1x2 / 4x2 用
  「图标 + 名称」排在底板里，透明 logo 与满色 logo 都不裁切、不拉伸
- **形状一眼可见** —— 1x1 只有图标本身；2x1 / 1x2 / 2x2 / 4x2 会铺一块与占位同形状、
  同大小的圆角矩形底板，横竖和大小不用数格子就能看出来
- **纵向严格对齐** —— 不管间距怎么调，方块底边永远落在下一行的顶线上：
  2 格高的底板就是「两个方块 + 一个行距」，不会比同排的 1×1 高一点或矮一点
- **外观可调** —— 设置里能调横向 / 纵向间距、图标圆角（0%–50%）、Logo 大小（60%–100%，只缩图案）、
  图标字号（0.75×–1.6×，旁边直接给出 1×1 上的实际 px），拖动滑杆即时生效，和布局一起保存；
  纵向间距有个下限，保证名称不会压到下一行图标
- **图标不再自带白边** —— 1×1 的图片图标不铺白色底板，favicon 的透明圆角直接融进壁纸。
  以前那层白底会从圆角和抗锯齿边缘透出来，看起来像「图标周围一圈白色像素」
- **图片自带的白描边也会被裁掉** —— 有些站点把 logo 做成「浅色描边 + 品牌色图形」，
  那圈描边本身就在抓下来的图里，铺在深色壁纸上就是一圈刺眼的白框。
  1×1 的图标按自身尺寸裁掉最外 5%（`--icon-trim`），正好落在白框上；
  透明底、图形居中的图标裁到的是留白，肉眼无差别（实测知乎 / 豆瓣 / B 站 / 微博都不变）
- **图标与外观一个弹窗改完** —— 右键「编辑图标与外观」：上面换图标（抓取 / 文字 / 上传 / 调整），
  下面直接调这一块的 Logo 大小、底色、名称颜色和字号
- **预览就是这一块本人** —— 左边那块预览不是另画的样板，而是把画布上这个方块整个克隆过来：
  类名、圆角、间距、底板、阴影、名称字号全是同一份，草稿只覆盖要改的那几个值。
  垫的是「这块图标背后那一小块壁纸」，所以透明图标透出来的颜色也和画布上一致。
  1×1 按 1:1 显示；展开后的方块装不下时整体等比缩小，并在下面写明「按 xx% 显示」
- **1×1 也能垫底色** —— 有些 favicon 是半透明的，直接铺在壁纸上会糊成一片；
  给它垫一层白（或任意颜色）就清楚了。底色块始终占满整格，不跟着图案缩放
- **透明留白会被挤掉** —— 有的 favicon 把图形画在中间、四周留一圈透明边，整张图放进
  格子就显得「没铺满」。加载后量一次内容边界（只看 alpha），把留白挤掉、内容放大到贴边，
  最多 1.35 倍。**只放大不裁切**：比例不动，所以图标不会被切成直角块，也不会压到名字上。
  四角都不透明的图（白卡、整块色块）一律不动 —— 它本身就是一块底板，放大只会把板裁掉一圈。
  量不到像素的图（后台取不回字节）保持原样，不会报错
- **只缩图案，不动底板** —— 弹窗里「Logo 大小」50%–100% 调的是图标**里面那张图**：
  底色块、它占的格子、名称位置都不动，只有图案在框里变大变小
  （带底色的方块最直观：白板不动，里面的 logo 缩进去）。图本身不透明时缩小会露出壁纸，
  先垫个底色就是「板子固定」的效果。只开放缩小——图案铺满时再放大会溢出到相邻格子里
- **上传 / 粘贴的图会自动处理** —— 按 `Ctrl+V` 就能把剪贴板里的图当图标，选文件也行。
  3000px 的大截图不会被拒收：先进「调整图片」页，最长边自动降到 1024 给你裁，
  拖位置、滚轮或滑杆缩放、「裁满 / 全图」二选一，确认后按同一套几何烘成正方形 WebP
  （最多 512×512，小图不会被硬放大，典型 10–60 KB）。存下来的不是原图，是裁好的结果，
  所以之后点「调整」还能再改
- **底色能从图标里取** —— 底色那一排末尾「从图标取色」：本地上传的图直接算出 4–6 个主色；
  远程图标由浏览器同源策略挡住像素，改用系统吸管在图标上点一下即可（读屏幕像素，不受限制）
- **展开后的方块** —— 底色变成整块底板（10 种预设 + 取色器），名称颜色自动 / 预设 / 取色器，
  这一块的名称字号 0.7×–1.8×；选了底色又没指定字色时按底色明暗自动配黑或白字
- **时钟能自己调样子** —— 右键「时钟设置」：字体（默认 / 衬线 / 等宽）、字重（极细 → 粗）、
  对齐（左 / 中 / 右）、制式（24 / 12 小时）、秒（显示 / 不显示）、补零（`09:05` / `9:05`）、
  日期（不显示 / 月日 / 月日+周 / 年月日+周 / 只看周几），以及**真实占位**（占几格 × 几行）
  和字号（相对「自动铺满」的 60%–100%）。左边预览就是画布上那一块克隆过来的，
  滑杆一动立刻变
- **字号不会溢出** —— 时间字号是按「最宽的那一帧」量出来的（`9:05` 跳到 `10:05`、
  12 小时制多了「上午」都不会撑出去），日期太长会自动缩到不超出占位；
  再把整块的高度也兜一次底，所以 4×2 这么小的格子也不会被裁
- **收起来也能看到什么变了** —— 右键菜单里直接有「24 / 12 小时」和「显示 / 隐藏日期」，
  改过的会在「时钟设置」上标「已自定义」
- **搜索框的尺寸也是真实占位** —— 「搜索框设置」里的宽度 / 高度写的是「12 格 · 688 px」，
  改的就是这一块实际占几格（别的方块会让位），不是缩放
- **搜索框自己长一条引擎行** —— 搜索条下面一横行引擎图标（必应 / 百度 / Google / GitHub /
  知乎 / DuckDuckGo），点哪个就切哪个，左边那颗当前引擎图标也能点开这一行；
  选中的引擎跨刷新保留，和右上角「搜索引擎」是同一份状态
- **搜索框能自己调外形** —— 右键「搜索框设置」：宽度（40%–100%）、高度（直接改这一块的格数，
  读数就是实际像素）、搜索条弧度（0 = 直角，50 = 胶囊）、字号、底色浓度、引擎图标大小、
  引擎行显示 / 隐藏。**左边预览就是画布上那一块**（克隆过来按真实像素排好再等比缩小），
  滑杆一动预览立刻变，保存后画布上分毫不差
- **装不下就自己变浮层** —— 把搜索块压到 2 格高时，引擎行不再挤在框里，改成点引擎图标
  才弹出来的浮层（靠页面底部时自动向上翻）；点空白处、按 `Esc`、选完引擎都会收起。
  老布局里的搜索块载入时会自动从 2 格升到 3 格（不撞到别的方块时），保证引擎行放得下
- **能加自己的搜索引擎** —— 引擎行末尾的「+」：填名字和搜索地址（用 `%s` 占位，
  漏写会提示并自动补成 `?q=`），最多 12 个；自定义引擎可以随时删掉，图标按名字首字取品牌色
- **图标抓不到也不开天窗** —— 引擎图标先摆品牌色字母块，真图回来再换上；候选链
  apple-touch-icon → favicon.ico → DuckDuckGo → Google s2，每个 1.6 秒超时，断网也照样能点
- **空白处右键 → 添加组件** —— 二级菜单里挑，目前三个：**天气**、**待办**、**月历**。
  加的时候就近找空位，找不到就往下排；落在屏幕外会自动滚过去
- **组件有卡面，颜色随便换** —— 右键「卡面…」：10 个预设底色（含「无」）、浓度 0–100%、
  圆角 0–32 px、模糊开关，上方预览就是这一块本身。卡面铺在组件下面，内容不受影响；
  浓度拉到 0 就等于不要卡面。颜色 / 浓度 / 圆角按块保存，只把改过的键写进存储
- **组件里的内容跟着尺寸变** —— 不是把同一份东西放大缩小，是按实际像素换内容：
  - **天气**：小 → 只剩图标和温度；中 → 加上城市、今日高低温，以及一行
    「天气名 · 体感」；再大 → 下面长出一排未来 6 天（周几 / 图标 /
    **低温 — 温度条 — 高温**，条的位置按整周的温度跨度定位），上面还有一行
    指标：湿度 / 风 / 气压 / 降水概率 / 日出 / 日落；最大 → 再加一排逐小时
    （温度 / 竖条 / 时刻，格数随宽度增加，最多 24 格）
  - 天气右键「天气显示…」还能选**版式**（自动 / 紧凑 / 详细）和**显示哪些块**
    （天气名 · 体感 / 未来几天 / 逐小时 / 指标行），勾掉的块直接不显示
  - **待办**：能放下几条显示几条，放不下的折成「还有 N 条」，点它展开成可滚动；块小到一定程度标题让位给列表
  - **月历**：放得下整月就是网格（今天高亮），小到 4×3 就只显示「今天」——大号日期 + 月份星期
  - 分档看的是**实际像素**不是格数，所以同一个组件在 1080p 和 4K、在 16 / 24 / 40 列密度下表现一致
- **组件也能调尺寸** —— 右键组件有「布局」档位（4x3 / 6x4 / 8x4 …），内容按实际占位重排，
  和时钟、搜索框一样
- **天气是真实数据，不编** —— 走 Open-Meteo（免 key）：`换城市` 先地理编码再取当天预报，
  每 15 分钟刷新一次；连不上就明说「连不上天气 / 右键重试」，并保留上一次读到的数字
- **加组件不用改渲染代码** —— 组件是一张注册表：`registerWidget(type, {name, icon, size,
  min, create, clean, mount, menu})`，注册进去就自动获得落位、尺寸下限、右键菜单、
  序列化、删除和拖动重排；数据统一存在 `item.data` 里，读回来先过各自的 `clean`
- **四套渐变背景 + Bing 每日壁纸** —— 设置抽屉里除了「晨曦 / 暮色 / 晨雾 / 墨夜」，
  还有 Bing 每日图（最近 8 天，一天一张）：点缩略图即换，再点一张取消，选预设会自动撤掉照片。
  换成照片时整套界面（玻璃、面板、文字）自动切到「深色 + 白字」，照片上再压一层暗角保证可读。
  列表缓存在本地 6 小时，只有打开抽屉时才去取
- **布局锁定 · Ctrl+F 本地搜索**
- **名称跟着壁纸走** —— 深色壁纸用白字加暗投影，浅色壁纸（朦胧）自动换成深字，避免白字糊在浅底上
- **数据可带走** —— 导出 / 导入备份，误删与误重置可撤销
- **工具栏上也有自己的标志** —— 扩展栏点 SudaTab 图标直接开一个新标签页；
  标签页的图标也换成了标志本身，不再是一个通用地球

## 安装

1. 打开 `edge://extensions`（Chrome 用 `chrome://extensions`）
2. 打开「开发人员模式」
3. 点「加载解压缩的扩展」，选中本目录

扩展只能接管**新标签页**。想让启动浏览器时也看到它：
Edge 设置 → 启动、主页和新建标签页 → 启动时 → 选「打开新标签页」。

加载后如果之前开过新标签页，需要关掉重开一次才会生效。
浏览器默认会把新扩展收进「扩展」菜单里，点一下图钉把它固定到工具栏，
之后按一下图标就能开新标签页。

## 基本操作

| 操作 | 效果 |
| --- | --- |
| 按住方块**任意位置**拖动 | 图标、名称、空白处都是拖动手柄，全程吸附整格；点一下仍是打开链接 |
| 拖**组件**右下角 | 组件（时钟 / 搜索 / 引语 / 天气 / 待办 / 月历）可以按格改大小，内容会跟着重排；站点图标不给这个热区——图标只站整格 |
| 方块上右键 | 布局尺寸、编辑图标与外观、重新抓取图标、编辑主页、时间制式、搜索引擎、删除 |
| 搜索框上右键 | 布局尺寸、搜索框设置（宽度 / 弧度 / 字号 / 底色 / 引擎行）、引擎切换、删除 |
| 时钟上右键 | 布局尺寸、时钟设置（字体 / 字重 / 对齐 / 制式 / 秒 / 补零 / 日期 / 占位）、删除 |
| 搜索条左边的引擎图标 | 引擎行收起时点它弹出来（浮层模式）；平时直接在下面一行里点着切 |
| 空白处右键 | 添加图标、**添加组件**（天气 / 待办 / 月历）、锁定/解锁布局、换壁纸、本地搜索、立即备份、设置 |
| 设置 → 背景 | 四套渐变主题 + **Bing 每日壁纸**（点缩略图即换，再点取消） |
| 菜单打开时点别处 | 收起菜单；那一下只负责关，不会顺带打开链接或把方块拖起来（和系统菜单一致） |
| 右上角齿轮 | 背景、搜索引擎、网格密度、外观（间距 / 圆角 / 字号）、快捷方式列表、备份与重置 |
| 编辑图标与外观里按 `Ctrl + V` | 把剪贴板里的图片直接当图标（截图、网页上复制来的图都行） |
| `Ctrl + F` | 按名称 / 网址过滤已添加的站点，回车打开第一条 |
| `Ctrl + Z` | 撤销最近一次删除、重置或导入 |
| `Esc` | 拖动中取消并弹回原位；平时关闭菜单 / 弹窗 / 抽屉 |

添加或编辑站点时会校验网址：自动补 `https://`，拒绝 `javascript:` / `data:` 等危险协议，
取消不会留下空白方块。改了网址后图标会跟着刷新。

## 自己加一个组件

组件是一张注册表，加新的一类不用碰布局、拖动、存储这些通用逻辑：

```js
registerWidget('clockish', {
  name: '名字',            // 「添加组件」里显示的名字
  desc: '一句话说明',       // 二级菜单里的提示
  icon: 'check',          // ICONS 里的图标名
  size: { w: 8, h: 4 },   // 默认占几格
  min:  { w: 4, h: 3 },   // 最小占几格（拖动、缩放都按它夹）
  sizes: [[4, 3], [8, 4]],// 右键「布局」里给的档位
  create: function () { return {}; },        // 新实例的初始 item.data
  clean: function (d) { return d; },         // 从存储读回来时洗一遍
  mount: function (item) {
    makeShell(item);                         // 建外壳，给出 item.el / item.body
    item.body.textContent = '…';
    item.fit = function (r) { /* 按 r.width / r.height 重排 */ };
  },
  menu: function (item) {                    // 右键里除「删除」之外的项
    return [mItem('做点什么', function () {}, { icon: 'reset' })];
  }
});
```

注册完就自动出现在「添加组件」里，并且拿到：就近落位、尺寸下限、右键布局档位、
`item.data` 的序列化与清洗、删除、拖动与挤入重排。

## 交互与动效

- 拖动时其它方块**实时就近挤入**（只改显示、不改数据）：重排从原位置向外螺旋搜索
  最近的空位，常见表现是「和邻居交换位置」，而不是把整列往下推。拖动块自己吸附在
  目标格上就是落点指示，不画彩色框；实在放不下只轻微压暗
- 松手弹性落位，按 `Esc` / 指针取消 / 窗口失焦则弹性弹回原位；让位方块用带过冲的
  spring 曲线滑动。拖动中窗口尺寸变化不会把正在跟手的方块拉回原位
- 拖到画布上下边缘会自动滚动，滚动量会计入落点计算，长布局也能一次拖到位
- 布局锁定后右上角常驻「布局已锁定」徽标，点它即可解锁；锁定状态跨刷新保留，
  不会再出现「不知道为什么拖不动」
- 右键菜单、确认框、方块添加/删除都有出入场动画；切换背景用旧背景层淡出做交叉淡化，
  避免 CSS 变量渐变切换时的硬跳
- 图标抓取成功有一次脉冲反馈；系统开启「减少动态效果」时会自动关闭装饰性动画

## 数据与备份

- 数据只存在本机 `chrome.storage.local`（直接在浏览器里打开 `newtab.html` 预览时退回
  `localStorage`），**不上传任何服务器**，扩展没有网络请求型权限。
- 设置 → 布局与数据 → **导出备份**，得到带版本号和导出时间的 JSON；**导入备份**会先校验
  文件结构与版本，确认后才整体覆盖，失败时绝不改动现有布局。备份里包含自定义图标
  （文字、颜色、上传的图片数据）。
- 删除方块、重置位置、恢复全部默认、导入备份都会保留一份快照，底部提示条点「撤销」
  或按 `Ctrl+Z` 即可还原。重置位置只重排坐标，不会删掉你添加的站点和图标。
- 存盘失败（配额不足 / 隐私模式）或读到损坏数据时会明确提示；损坏的原始值会另存一份，
  不会被静默清空。

## 关于图标抓取

「编辑图标 → 获取图标」会并发尝试站点自托管的 `apple-touch-icon.png` / `favicon.ico`、
主域同名路径，再退到第三方图标服务与浏览器 favicon 缓存，取第一个真实可加载的图。
它**只探测约定路径**，不会解析目标网页的 HTML，因此少数把 `<link rel="icon">` 指向
非标准路径的站点可能抓不到——这时可以用文字图标或本地上传。
探测只走约定路径、不解析网页 HTML，因此只申请了 `<all_urls>` 用来读图标字节
（见下面「自动撑满」），没有被用来注入或修改任何页面。

抓到的地址会**按域名记在本地**（`localStorage` 的 `sudatab.icons.v1`），
下次打开新标签页直接用它，不再从头把候选链试一遍：缓存命中时 14 个图标
约 0.2 秒全部就位，冷启动一轮约 1.8 秒。记下的地址失效（站点换图标、图床挂了）
会自动丢弃并重抓；整条链都没抓到的域名也记一笔，半小时内直接显示首字母，
不会让页面空等。站点换图标后想手动刷新，右键方块 →「重新抓取图标」。
缓存的是**已经验证可用的地址**，不是图片字节本身——浏览器自己的磁盘缓存会兜住这次请求。

跨域图片在页面里读不出像素（`canvas` 一画就 taint，`SecurityError`），所以量留白时
改由后台 `bg.js` 带着 host 权限去 fetch：拿回来的字节转成 data URL 就同源了，
可以放心量。这条通道只读图片，用完即弃，不落盘、不外发。

同一条限制还决定了「从图标取色」的做法：**自动算出配色只对本地上传的图有效**。
远程图标退回系统吸管（EyeDropper）——它读的是屏幕上合成好的像素，不受同源限制，
图标就摆在弹窗的预览里，点一下就能取到准确的色值（顺便也能取壁纸的颜色）。
试过 Chrome 的 `/_favicon/` 接口（扩展同源、可以读），但它返回的是浏览器 favicon 库里
的记录：没访问过的站点一律给同一张默认图，等于没有，所以没有采用。

## 已知限制

- 三个组件里只有天气联网（Open-Meteo，每 15 分钟一次）；待办和月历只读本机数据。
  没有 RSS 订阅，也没有农历
- 尺寸只能在右键的五档里切换，不能自由拉伸
- 单块字号只对展开后的方块开放：1×1 的名称挂在方块外面、正好住在行与行的空隙里，
  单独放大就会压到下一行，所以 1×1 的名称字号跟着设置里的「图标字号」走
  （图案大小、底色和名称颜色对 1×1 一样有效）
- 单块的「Logo 大小」只开放缩小（50%–100%）：图案本来就铺满容器，放大会溢出到相邻格子里
- 上传的图会被**烘成静态一帧**：GIF 动图只取第一帧，带宏动画的 SVG 也一样。
  没有内建尺寸的 SVG（只写了 `viewBox`）浏览器读不出宽高，会提示读不出来，先导出成 PNG 再传
- 烘焙尺寸固定 512×512（够 4×4 大方块按 2× DPR 显示），所以图会被裁成正方形——
  想保留整张图就用「全图」，四周留空的部分是透明的
- 预览对 1×1 是 1:1，展开后的方块（2×2 实测 221×239 px）在弹窗里放不下，会等比缩到
  六成左右并注明比例——样式仍然完全一致，只是尺寸是缩略图
- 从图标取色对**远程图标**只能靠吸管（要自己点一下），自动配色只对上传的本地图有效——
  跨域图片读不到像素，这是浏览器的同源策略，不是没做
- 「挤掉透明留白」需要量图片的像素。远程图标靠后台 `bg.js` 先 fetch 成 data URL 再量，
  所以 manifest 里申请了 `<all_urls>`：**只用来取图标字节，不改页面、不传数据**。
  权限被拒或取不到（403 / 非图片）时自动跳过，图标照常显示。
  放大上限 1.35：再大就会把 32px 的小 favicon 拉成马赛克
- 吸管取色需要浏览器支持 `EyeDropper`（Edge / Chrome 95+）；不支持时会提示改用色板
- 网格密度变化时站点方块会重新打包，原本精心摆的位置不保留
- 1×1 的图标不铺底板：完全靠图自己成形，所以「透明背景的白色字形」在浅色壁纸下会偏淡
  （默认四套壁纸里没这个问题）；想要一块白砖的话垫个底色即可，「Logo 大小」只管图案
- 白描边只裁「真的是描边」的那种：四条边都有浅色窄边、宽度还基本一致（差 ≤2px）、
  都不超过 6% 时才按实测宽度裁掉一点。满幅 logo、白底卡片一律不裁 —— 以前一刀切
  裁 5%，会把这些图的图形啃掉一角，看起来就是「抓到的图是完整的、显示出来缺一块」
- 密度很高又想要大间距时（如 64 列 + 32px），间距会把格子挤小，此时实际间距会按
  「1×1 仍是正方形」自动回收一点，滑杆上的数值是上限而不是精确值
- 纵向间距拉得很大时，2×2 这类多格底板会比「正方」略高——它铺的是「两格方块 + 一个行距」，
  这样底边才和同排的 1×1 对齐；横向间距和纵向间距差得越多，这个高宽比越明显
- 尚未做移动端触屏适配（依赖右键与鼠标拖动）

## 文件

```
bg.js                      后台 service worker：取图标字节；点工具栏图标开新标签页

```

纯静态、零依赖、无构建步骤。改完代码在扩展管理页点「刷新」即可生效。
